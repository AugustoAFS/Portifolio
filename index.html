III. Projetos Forjados

Projetos Back-end

API de Gestão de Inventário

POST /api/v1/auth/login GET /api/v1/product?page=1 PUT /api/v1/product/{id} DEL /api/v1/product/{id} GET /api/v2/category

API REST de gestão de inventário com autenticação JWT e hash Argon2, cache distribuído com Redis, versionamento de API (v1/v2) e autorização por roles. Arquitetura em camadas com Repository Pattern, FluentValidation, mapeamento source-generated via Mapperly e documentação Scalar. Containerizada com Docker e coberta por testes unitários.
